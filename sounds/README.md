# 効果音

`sd/` の中身 (`mp3` フォルダごと) を microSD カードのルートにコピーして、親機の DFPlayer Mini に挿してください。

```
microSD
└── mp3
    ├── 0001.mp3   正解     ピンポーン
    ├── 0002.mp3   不正解   ブッブー
    ├── 0003.mp3   回答権   ピコーン
    └── 0004.mp3   起動音   ドミソ
```

- microSD は 32GB 以下を FAT32 でフォーマットしてください
- 好きな音に変えたいときは、同じファイル名の mp3 で上書きするだけです
- 同梱の音は `generate_sounds.py` で合成したオリジナルなので、自由に使えます (MIT License)
- Mac でコピーすると `._0001.mp3` のような隠しファイルができることがありますが、`/mp3` フォルダの番号指定再生では問題ありません

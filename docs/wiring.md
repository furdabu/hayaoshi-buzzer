# 配線

このページは回路の説明です。**実際にはんだ付けするときは、線 1 本ずつ番号を付けた
[はんだ付けマニュアル](soldering-guide.md) を見てください。**

ピン番号は `firmware/include/config.h` で変更できます。下の表は初期値です。

- ボタンはすべて **GPIO と GND の間** につなぎます (ESP32 内部のプルアップを使うので抵抗は不要)
- アーケードボタンのマイクロスイッチは 3 端子 (COM / NO / NC) です。**COM と NO** を使います
- 親機の開発ボードの `5V` ピンは、ボードによって `VIN` と書かれています
- **外付けアンテナは不要です。** どちらの基板にもアンテナが付いていて、2.4GHz の電波は PETG のケースを通ります。
  基板のアンテナ部分を金属 (電池・スピーカー) から離し、壁側に向けて置いてください ([組み立て](assembly.md))

## 子機 (ESP32-C3 SuperMini)

```
 ESP32-C3 SuperMini
 ├ GPIO3 ───────────── ボタン NO
 ├ GND ─────────────── ボタン COM
 ├ GPIO4 ── 330Ω ───── LED 基板 IN
 ├ 5V ── 1N4001 ─┬──── LED 基板 PWR   (ダイオードは帯のある側を LED 基板へ)
 │        470〜1000µF
 ├ GND ──────────┴──── LED 基板 GND
 ├ GPIO1 ──────────── 電池電圧の測定 (下の「電源回路」)
 ├ GPIO5 ──── 1kΩ ─── ボタン LED 用トランジスタ (下の「ボタン内蔵 LED (12V)」)
 └ 5V / GND には下の「電源回路」(電池 1 本) から 5V を入れる
```

| 接続するもの | 端子 | ESP32-C3 SuperMini のピン |
| --- | --- | --- |
| アーケードボタン | NO | GPIO3 |
| | COM | GND |
| WS2812B 7 連 LED 基板 | IN | GPIO4 (**330Ω を直列に**) |
| | PWR | 5V (**1N4001 を直列に**) |
| | GND | GND |
| 電解コンデンサ 470〜1000µF (10V 以上) | + / − | LED 基板の 5V / GND の間 (極性に注意) |
| 電池電圧の測定 | 分圧の中点 | GPIO1 |
| ボタン内蔵 LED | (下の回路) | GPIO5 |

- 基板上の青い LED (GPIO8) は動作確認用です。親機につながると点灯、つながらないと点滅します
- GPIO2・GPIO8・GPIO9 は起動時の動作に関わるピンなので、上の表以外の用途には使わないでください
- **LED 基板の 5V に 1N4001 を入れる理由**: WS2812B は電源が 5.1V だと信号に 3.57V 以上が必要ですが、マイコンの信号は 3.3V です。
  ダイオードで LED の電源を約 4.3V に下げると、3.3V の信号を確実に受けられるようになります (明るさはほとんど変わりません)
- 7 連基板のパッド (`IN` `PWR` `GND` `OUT`) は LED 側の面にあります。`OUT` は使いません

### ボタン内蔵 LED (12V)

ボタンの中の LED は 12V 用なので、**2 個目の MT3608 で 12V を作り**、NPN トランジスタで ON / OFF します。
子機・親機とも同じ回路です。

- **子機**: ボタンが「今押せる」ときだけ点灯。トランジスタのベースは SuperMini の **GPIO5** から
- **親機**: 正解・不正解ボタンが「判定待ち (回答者が決まった)」のときに点灯、番号登録モード中は点滅。
  2 個のボタンの LED を **並列** (+ 同士、− 同士) にして 1 個のトランジスタにつなぎ、ベースは ESP32 の **GPIO26** から

```
 電源ボタンの後ろ (5V 用 MT3608 の VIN+ と同じところ) ─── MT3608 (12V 用) VIN+
 TP4056 OUT− (GND) ─────────────────────────────────── MT3608 (12V 用) VIN−

 MT3608 (12V 用) VOUT+ (12V に調整済み) ─── ボタン LED (+)      (親機は 2 個の + をまとめて)
                                            ボタン LED (−) ─── C  (親機は 2 個の − をまとめて)
                                                               │  NPN (2SC1815 / 2N2222 など)
 子機 GPIO5 / 親機 GPIO26 ─── 1kΩ ───────────────────────┬──── B
                                                          10kΩ  │
 GND ─────────────────────────────────────────────────────┴──── E
```

- **12V 用の MT3608 は、ボタン LED をつなぐ前にテスターで出力を 12V に合わせてください**
  (調整前は 12V より高い電圧が出ていることがあり、LED を傷めます)
- ボタンの LED には向きがあります。光らないときは LED の + と − を入れ替えてください
- トランジスタの足の並びは品種によって違います (2SC1815 は平らな面を見て左から E・C・B)。データシートで確認してください
- ベースと GND の間の 10kΩ は、起動中や書き込み中に LED がぼんやり光るのを防ぎます
- 明るさは `config.h` の `BUTTON_LED_LEVEL` (0〜255) で変えられます

## 親機 (ESP32 開発ボード)

```
 ESP32 開発ボード
 ├ GPIO32 ──────────── 正解ボタン NO
 ├ GPIO33 ──────────── 不正解ボタン NO
 ├ GND ─────────────── 両ボタンの COM
 ├ GPIO27 ── 330Ω ──── 中央ランプの LED 基板 IN
 ├ GPIO17 ── 1kΩ ───── DFPlayer RX
 ├ GPIO16 ── 1kΩ ───── DFPlayer TX
 │                     DFPlayer SPK_1 / SPK_2 ──── スピーカー (8Ω)
 │                     DFPlayer VCC ──── 電池の線 (下の「電源回路」。5V ではない)
 ├ GPIO18 ──────────── TM1637 CLK
 ├ GPIO19 ──────────── TM1637 DIO
 ├ 3V3 ─────────────── TM1637 VCC   (5V ではなく 3.3V)
 ├ GPIO26 ── 1kΩ ───── ボタン LED 用トランジスタ (上の「ボタン内蔵 LED (12V)」)
 ├ 5V (VIN) ── 1N4001 ─┬──── LED 基板の 5V (PWR)
 │                   1000µF
 ├ GND ────────────────┴──── すべての GND
 └ 5V (VIN) / GND には下の「電源回路」(電池 3 本) から 5V を入れる
```

| 接続するもの | 端子 | ESP32 のピン |
| --- | --- | --- |
| 正解ボタン (赤, 右) | NO / COM | GPIO32 / GND |
| 不正解ボタン (青, 左) | NO / COM | GPIO33 / GND |
| 中央ランプの WS2812B 7 連 LED 基板 | IN | GPIO27 (**330Ω を直列に**) |
| | PWR / GND | 5V (**1N4001 を直列に**) / GND |
| DFPlayer Mini | VCC / GND | **電池の線** (電源ボタンの後ろ, 下の「電源回路」) / GND。VCC と GND の間に 1000µF |
| | RX | GPIO17 (**1kΩ を直列に**) |
| | TX | GPIO16 (**1kΩ を直列に**) |
| | SPK_1 / SPK_2 | スピーカー (8Ω) の 2 本の線 |
| TM1637 4 桁表示 | CLK / DIO | GPIO18 / GPIO19 |
| | VCC / GND | **3V3** / GND |
| 正解・不正解ボタンの内蔵 LED | (上の「ボタン内蔵 LED (12V)」の回路) | GPIO26 |
| 電解コンデンサ 1000µF (10V 以上) | + / − | LED 基板の 5V / GND の間、DFPlayer の VCC / GND の間 (計 2 個) |

> **TM1637 は 3.3V で使ってください。** モジュール上のプルアップ抵抗が VCC につながっているので、
> 5V で動かすと ESP32 のピンに 5V がかかります。

## 電源回路 (親機・子機共通)

18650 電池から次の回路で 5V を作り、開発ボードの `5V (VIN)` ピンと各部品に配ります。
子機は電池 1 本、親機は電池 3 本を並列にします。

```
 18650 (+) ─── TP4056 B+        (親機は 3 本の + をまとめて)
 18650 (−) ─── TP4056 B−        (親機は 3 本の − をまとめて)
                TP4056 OUT+ ─── 電源ボタン ──┬──────────── MT3608 VIN+
                TP4056 OUT− ─────────────────┼──────────── MT3608 VIN−
                                             │
                                           100kΩ
                                             ├──────────── 子機 GPIO1 / 親機 GPIO35
                                           100kΩ  0.1µF
                                             │      │
                TP4056 OUT− ─────────────────┴──────┘

 MT3608 VOUT+ (5.1V に調整済み) ─── 5V の束 (ESP32 5V / LED 基板 (ダイオード経由) / 電源ボタンの LED)
 MT3608 VOUT− ───────────────────── GND の束
 (ボタン LED 用の 12V 用 MT3608 も同じ VIN+ / VIN− につなぐ)
 (親機は DFPlayer の VCC も 電源ボタンの後ろ = MT3608 VIN+ と同じところ につなぐ)
 電源ボタンの LED + ─── 5V の束     電源ボタンの LED − ─── GND の束   (電源 ON の間だけ光る)
 TP4056 の Type-C ← 充電
```

| つなぐもの | つなぐ先 |
| --- | --- |
| 電池ボックスの + / − | TP4056 の `B+` / `B-` |
| TP4056 の `OUT+` | 電源ボタンのスイッチ端子 (2 本のどちらか) |
| 電源ボタンのもう一方のスイッチ端子 | MT3608 の `VIN+` |
| 電源ボタンの LED 端子 `+` / `−` | 5V の束 / GND の束 (子機の Pten は 3-6V 用、親機の LA16 は 6V 用の LED なので、どちらも 5V にそのままつなげる) |
| TP4056 の `OUT-` | MT3608 の `VIN-` |
| (親機のみ) DFPlayer の `VCC` | 電源ボタンの後ろ (MT3608 `VIN+` と同じところ) |
| MT3608 の `VOUT+` / `VOUT-` | 5V の束 / GND の束 |
| 電池電圧の測定 | 電源ボタンの後ろ (MT3608 `VIN+`) → 100kΩ → **子機 GPIO1 / 親機 GPIO35** → 100kΩ → `OUT-`。そのピンと GND の間に 0.1µF |

- **親機の電池 3 本は並列** (3 本の + 同士、3 本の − 同士) にして `B+` / `B-` へ。つなぐ前に 3 本とも満充電して電圧をそろえる
- GND は **TP4056 の `OUT-`** 側を使います (`B-` ではありません。保護回路が間に入っているため)。MT3608 の `VIN-` と `VOUT-` はつながっています
- 電源ボタンは子機が Pten 16mm (1A)、親機が LA16 16mm (5A) です。親機は音を鳴らすと電池側に 1.5A 以上流れるので、
  1A のボタンは使わないでください
- 電源ボタンの端子は「スイッチ用」と「LED 用」があります。LED 用は根元や端子の横に `+` `−` の印があります。
  スイッチ用の端子が 3 本 (C / NO / NC) のものは **C と NO** を使います
  (わからないときは、テスターの導通チェックで「押すたびにつながったり切れたりする 2 本」がスイッチ用)
- **充電は必ず電源ボタンを OFF にして行ってください。** ON のままだと満充電を判断できません。OFF でも Type-C をつなげば充電されます
- ファームウェアを書き込むときは、**電源ボタンを OFF にしてから** 開発ボードに USB ケーブルをつないでください
  (MT3608 の 5V と パソコンの USB の 5V がぶつからないように)。このときパソコンの USB から LED や電源ボタンの LED にも
  電気が流れて光ることがありますが、異常ではありません。親機は USB の電流が足りないことがあるので、
  書き込みがうまくいかないときは LED 基板の 5V 線を外してから書き込んでください

### 5V と GND の分配

5V と GND はたくさんの部品に配ります。このページの「5V の束」「GND の束」は、
[はんだ付けマニュアル](soldering-guide.md) の **中継基板** の 9 行 (5V) と 3・4 行 (GND) のことです。
抵抗・ダイオード・コンデンサ・トランジスタも、同じ中継基板にまとめてはんだ付けします。

## うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| LED 基板がちらつく / 色がおかしい | LED 基板の 5V に 1N4001 が入っているか (向きも)、データ線の 330Ω、GND の共通化、配線の短さ |
| 子機のランプが青く点滅し続ける | 親機の電源、`WIFI_CHANNEL` と `GROUP_ID` が親機と同じか |
| 一部の子機だけ通信が途切れる | ESP32-C3 SuperMini は個体によって最大出力だと電波が不安定なことがあります。`-DWIFI_TX_POWER=WIFI_POWER_8_5dBm` を付けて書き込んでみてください |
| 子機・親機が急に赤く 3 回光って止まった | 電池切れ寸前で休止しました。充電してから電源ボタンを入れ直してください |
| 音が出ない | microSD が FAT32 か、`/mp3/0001.mp3` の位置にファイルがあるか。シリアルログに `DFPlayer OK` が出ているか。互換品は `DFPLAYER_SKIP_CHECK=1` で動くことがあります |
| 音を鳴らすと親機がリセットする | 電源の電圧が一瞬下がっています。DFPlayer が 5V ではなく電池の線から給電されているか、スピーカーが 8Ω か、電源ボタンが 5A の LA16 か、電池が充電されているかを確認。直らなければ `AUDIO_VOLUME` を下げる |
| 電池残量の表示がおかしい | シリアルログの `[battery]` の電圧をテスターの値と比べて、`BATTERY_DIVIDER` を微調整 (例: 実際より 2% 低いなら 2.04) |
| Type-C で充電できない | C-to-C ケーブルだと充電できない TP4056 モジュールがあります。USB-A to C ケーブルで試してください |
| ボタンを押しても反応しない | シリアルログに `[press]` が出るか。マイクロスイッチの COM / NO を使っているか |

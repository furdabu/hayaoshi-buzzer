# 配線

ピン番号は `firmware/include/config.h` で変更できます。下の表は初期値です。

- ボタンはすべて **GPIO と GND の間** につなぎます (ESP32 内部のプルアップを使うので抵抗は不要)
- アーケードボタンのマイクロスイッチは 3 端子 (COM / NO / NC) です。**COM と NO** を使います
- 親機の開発ボードの `5V` ピンは、ボードによって `VIN` と書かれています

## 子機 (ESP32-C3 SuperMini)

```
 ESP32-C3 SuperMini
 ├ GPIO3 ───────────── ボタン NO
 ├ GND ─────────────── ボタン COM
 ├ GPIO4 ── 330Ω ───── LED 基板 DIN
 ├ 5V ───────────┬──── LED 基板 5V
 │             1000µF
 ├ GND ──────────┴──── LED 基板 GND
 ├ GPIO1 ──────────── 電池電圧の測定 (下の「電源回路」)
 ├ GPIO5 ──── 1kΩ ─── ボタン LED 用トランジスタ (下の「ボタン内蔵 LED (12V)」)
 └ 5V / GND には下の「電源回路」(電池 1 本) から 5V を入れる
```

| 接続するもの | 端子 | ESP32-C3 SuperMini のピン |
| --- | --- | --- |
| アーケードボタン | NO | GPIO3 |
| | COM | GND |
| WS2812B 7 連 LED 基板 | DIN (DI) | GPIO4 (**330Ω を直列に**) |
| | 5V (VCC) | 5V |
| | GND | GND |
| 電解コンデンサ 470〜1000µF | + / − | LED 基板の 5V / GND の間 (極性に注意) |
| 電池電圧の測定 | 分圧の中点 | GPIO1 |
| ボタン内蔵 LED | (下の回路) | GPIO5 |

- 基板上の青い LED (GPIO8) は動作確認用です。親機につながると点灯、つながらないと点滅します
- GPIO2・GPIO8・GPIO9 は起動時の動作に関わるピンなので、上の表以外の用途には使わないでください

### ボタン内蔵 LED (12V)

ボタンの中の LED は 12V 用なので、**2 個目の MT3608 で 12V を作り**、NPN トランジスタで ON / OFF します。
子機・親機とも同じ回路です。

- **子機**: ボタンが「今押せる」ときだけ点灯。トランジスタのベースは SuperMini の **GPIO5** から
- **親機**: 正解・不正解ボタンが「判定待ち (回答者が決まった)」のときに点灯、番号登録モード中は点滅。
  2 個のボタンの LED を **並列** (+ 同士、− 同士) にして 1 個のトランジスタにつなぎ、ベースは ESP32 の **GPIO26** から

```
 電源ボタンの後ろ (5V 用 MT3608 の VIN+ と同じところ) ─── MT3608 (12V 用) VIN+
 TP4056 OUT− (GND) ─────────────────────────────────── MT3608 (12V 用) VIN−

 MT3608 (12V 用) VOUT+ (12V に調整済み) ─── ボタン LED (+)      (親機は 2 個の + をまとめて)
                                            ボタン LED (−) ─── C  (親機は 2 個の − をまとめて)
                                                               │  NPN (2SC1815 / 2N2222 など)
 子機 GPIO5 / 親機 GPIO26 ─── 1kΩ ──────────────────────────── B
                                                               │
 GND ───────────────────────────────────────────────────────── E
```

- **12V 用の MT3608 は、ボタン LED をつなぐ前にテスターで出力を 12V に合わせてください**
  (調整前は 12V より高い電圧が出ていることがあり、LED を傷めます)
- ボタンの LED には向きがあります。光らないときは LED の + と − を入れ替えてください
- トランジスタの足の並びは品種によって違います (2SC1815 は平らな面を見て左から E・C・B)。データシートで確認してください
- 明るさは `config.h` の `BUTTON_LED_LEVEL` (0〜255) で変えられます

## 親機 (ESP32 開発ボード)

```
 ESP32 開発ボード
 ├ GPIO32 ──────────── 正解ボタン NO
 ├ GPIO33 ──────────── 不正解ボタン NO
 ├ GND ─────────────── 両ボタンの COM
 ├ GPIO27 ── 330Ω ──── 緑ランプの基板 DIN
 │                     緑ランプの基板 DOUT ── 赤ランプの基板 DIN
 ├ GPIO17 ── 1kΩ ───── DFPlayer RX
 ├ GPIO16 ──────────── DFPlayer TX
 │                     DFPlayer SPK_1 / SPK_2 ──── スピーカー
 ├ GPIO18 ──────────── TM1637 CLK
 ├ GPIO19 ──────────── TM1637 DIO
 ├ 3V3 ─────────────── TM1637 VCC   (5V ではなく 3.3V)
 ├ GPIO26 ── 1kΩ ───── ボタン LED 用トランジスタ (上の「ボタン内蔵 LED (12V)」)
 ├ 5V (VIN) ─────┬──── LED 基板 x2 / DFPlayer の 5V
 │             1000µF
 ├ GND ──────────┴──── すべての GND
 └ 5V (VIN) / GND には下の「電源回路」(電池 3 本) から 5V を入れる
```

| 接続するもの | 端子 | ESP32 のピン |
| --- | --- | --- |
| 正解ボタン (緑) | NO / COM | GPIO32 / GND |
| 不正解ボタン (赤) | NO / COM | GPIO33 / GND |
| 緑ランプ (LED 基板 1 個目) | DIN | GPIO27 (**330Ω を直列に**) |
| | DOUT | 赤ランプの DIN へ |
| 赤ランプ (LED 基板 2 個目) | DIN | 緑ランプの DOUT から |
| LED 基板 2 個とも | 5V / GND | 5V / GND |
| DFPlayer Mini | VCC / GND | 5V / GND |
| | RX | GPIO17 (**1kΩ を直列に**) |
| | TX | GPIO16 |
| | SPK_1 / SPK_2 | スピーカーの 2 本の線 |
| TM1637 4 桁表示 | CLK / DIO | GPIO18 / GPIO19 |
| | VCC / GND | **3V3** / GND |
| 正解・不正解ボタンの内蔵 LED | (上の「ボタン内蔵 LED (12V)」の回路) | GPIO26 |
| 電解コンデンサ 1000µF | + / − | 5V / GND の間 |

> **TM1637 は 3.3V で使ってください。** モジュール上のプルアップ抵抗が VCC につながっているので、
> 5V で動かすと ESP32 のピンに 5V がかかります。

## 電源回路 (親機・子機共通)

18650 電池から次の回路で 5V を作り、開発ボードの `5V (VIN)` ピンと各部品に配ります。
子機は電池 1 本、親機は電池 3 本を並列にします。

```
 18650 (+) ─── TP4056 B+        (親機は 3 本の + をまとめて)
 18650 (−) ─── TP4056 B−        (親機は 3 本の − をまとめて)
                TP4056 OUT+ ─── 電源ボタン ──┬──────────── MT3608 VIN+
                TP4056 OUT− ─────────────────┼──────────── MT3608 VIN−
                                             │
                                           100kΩ
                                             ├──────────── 子機 GPIO1 / 親機 GPIO35
                                           100kΩ  0.1µF
                                             │      │
                TP4056 OUT− ─────────────────┴──────┘

 MT3608 VOUT+ (5.1V に調整済み) ─── 5V の束 (ESP32 5V / LED 基板 / DFPlayer)
 MT3608 VOUT− ───────────────────── GND の束
 (ボタン LED 用の 12V 用 MT3608 も同じ VIN+ / VIN− につなぐ)
 電源ボタンの LED + ─── 5V の束     電源ボタンの LED − ─── GND の束   (電源 ON の間だけ光る)
 TP4056 の Type-C ← 充電
```

| つなぐもの | つなぐ先 |
| --- | --- |
| 電池ボックスの + / − | TP4056 の `B+` / `B-` |
| TP4056 の `OUT+` | 電源ボタンのスイッチ端子 (2 本のどちらか) |
| 電源ボタンのもう一方のスイッチ端子 | MT3608 の `VIN+` |
| 電源ボタンの LED 端子 `+` / `−` | 5V の束 / GND の束 (3-6V 用 LED なので 5V にそのままつなげる) |
| TP4056 の `OUT-` | MT3608 の `VIN-` |
| MT3608 の `VOUT+` / `VOUT-` | 5V の束 / GND の束 |
| 電池電圧の測定 | 電源ボタンの後ろ (MT3608 `VIN+`) → 100kΩ → **子機 GPIO1 / 親機 GPIO35** → 100kΩ → `OUT-`。そのピンと GND の間に 0.1µF |

- **親機の電池 3 本は並列** (3 本の + 同士、3 本の − 同士) にして `B+` / `B-` へ。つなぐ前に 3 本とも満充電して電圧をそろえる
- GND は **TP4056 の `OUT-`** 側を使います (`B-` ではありません。保護回路が間に入っているため)。MT3608 の `VIN-` と `VOUT-` はつながっています
- 電源ボタンの端子は 4 本あります。根元や端子の横に `+` `−` の印があるのが LED 用、残りの 2 本がスイッチ用です
  (印が見つからないときは、テスターの導通チェックで「押すたびにつながったり切れたりする 2 本」がスイッチ用)
- 電源ボタンが OFF でも、Type-C をつなげば電池は充電されます (充電は OFF のまま行うのがおすすめ)
- ファームウェアを書き込むときは、**電源ボタンを OFF にしてから** 開発ボードに USB ケーブルをつないでください
  (MT3608 の 5V と パソコンの USB の 5V がぶつからないように)

### 5V と GND の分配

5V と GND をたくさんの部品に配るので、小さなユニバーサル基板や、レバー式の電線コネクタ (WAGO 221 など) で
「5V の束」と「GND の束」を作ると楽です。

## うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| LED 基板がちらつく / 色がおかしい | データ線の 330Ω、GND の共通化、配線の短さ。直らなければ LED 基板の 5V をダイオード (1N4001 など) 1 本経由にすると安定することがあります (データ信号の 3.3V で受けられるようになるため) |
| 子機のランプが青く点滅し続ける | 親機の電源、`WIFI_CHANNEL` と `GROUP_ID` が親機と同じか |
| 音が出ない | microSD が FAT32 か、`/mp3/0001.mp3` の位置にファイルがあるか。シリアルログに `DFPlayer OK` が出ているか。互換品は `DFPLAYER_SKIP_CHECK=1` で動くことがあります |
| 音を鳴らすと親機がリセットする | 電源の電圧が一瞬下がっています。電池が充電されているか、MT3608 の出力が 5.0〜5.1V か、5V に 1000µF のコンデンサがあるかを確認。直らなければ `AUDIO_VOLUME` を下げる |
| 電池残量の表示がおかしい | シリアルログの `[battery]` の電圧をテスターの値と比べて、`BATTERY_DIVIDER` を微調整 (例: 実際より 2% 低いなら 2.04) |
| Type-C で充電できない | C-to-C ケーブルだと充電できない TP4056 モジュールがあります。USB-A to C ケーブルで試してください |
| ボタンを押しても反応しない | シリアルログに `[press]` が出るか。マイクロスイッチの COM / NO を使っているか |

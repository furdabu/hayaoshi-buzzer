# 配線

ピン番号は `firmware/include/config.h` で変更できます。下の表は初期値です。

- ボタンはすべて **GPIO と GND の間** につなぎます (ESP32 内部のプルアップを使うので抵抗は不要)
- アーケードボタンのマイクロスイッチは 3 端子 (COM / NO / NC) です。**COM と NO** を使います
- 開発ボードの `5V` ピンは、ボードによって `VIN` と書かれています

## 子機 (ESP32 開発ボード)

```
 ESP32 開発ボード
 ├ GPIO32 ──────────── ボタン NO
 ├ GND ─────────────── ボタン COM
 ├ GPIO27 ── 330Ω ──── LED リング DIN
 ├ 5V (VIN) ─────┬──── LED リング 5V
 │             1000µF
 ├ GND ──────────┴──── LED リング GND
 ├ GPIO26 ──────────── (任意) ボタン LED 回路
 └ USB ─────────────── 電源 (USB 充電器 / モバイルバッテリー)
```

| 接続するもの | 端子 | ESP32 のピン |
| --- | --- | --- |
| アーケードボタン | NO | GPIO32 |
| | COM | GND |
| WS2812B LED リング | DIN (DI) | GPIO27 (**330Ω を直列に**) |
| | 5V (VCC) | 5V |
| | GND | GND |
| 電解コンデンサ 470〜1000µF | + / − | LED リングの 5V / GND の間 (極性に注意) |

### 子機 (ESP32-C3 SuperMini の場合)

| 接続するもの | 端子 | ESP32-C3 のピン |
| --- | --- | --- |
| アーケードボタン | NO / COM | GPIO3 / GND |
| WS2812B LED リング | DIN / 5V / GND | GPIO4 (330Ω 経由) / 5V / GND |
| (任意) ボタン LED | 下記の回路 | GPIO5 |

### 任意: ボタン内蔵 LED

GPIO から直接は電流が足りないので、トランジスタで点灯させます。

```
  5V ───────────────── ボタン LED (+)
                       ボタン LED (−) ── C
                                         │  NPN (2SC1815 など)
  GPIO26 ── 1kΩ ────────────────────── B
                                         │
  GND ───────────────────────────────── E
```

## 親機 (ESP32 開発ボード)

```
 ESP32 開発ボード
 ├ GPIO32 ──────────── 正解ボタン NO
 ├ GPIO33 ──────────── 不正解ボタン NO
 ├ GND ─────────────── 両ボタンの COM
 ├ GPIO27 ── 330Ω ──── 緑リング DIN
 │                     緑リング DOUT ──── 赤リング DIN
 ├ GPIO17 ── 1kΩ ───── DFPlayer RX
 ├ GPIO16 ──────────── DFPlayer TX
 │                     DFPlayer SPK_1 / SPK_2 ──── スピーカー
 ├ GPIO18 ──────────── TM1637 CLK
 ├ GPIO19 ──────────── TM1637 DIO
 ├ 3V3 ─────────────── TM1637 VCC   (5V ではなく 3.3V)
 ├ GPIO25 ──────────── (任意) 圧電ブザー +
 ├ 5V (VIN) ─────┬──── LED リング x2 / DFPlayer の 5V
 │             1000µF
 ├ GND ──────────┴──── すべての GND
 └ USB ─────────────── 電源 (5V 2A 以上)
```

| 接続するもの | 端子 | ESP32 のピン |
| --- | --- | --- |
| 正解ボタン (緑) | NO / COM | GPIO32 / GND |
| 不正解ボタン (赤) | NO / COM | GPIO33 / GND |
| 緑ランプ (LED リング 1 個目) | DIN | GPIO27 (**330Ω を直列に**) |
| | DOUT | 赤ランプの DIN へ |
| 赤ランプ (LED リング 2 個目) | DIN | 緑ランプの DOUT から |
| LED リング 2 個とも | 5V / GND | 5V / GND |
| DFPlayer Mini | VCC / GND | 5V / GND |
| | RX | GPIO17 (**1kΩ を直列に**) |
| | TX | GPIO16 |
| | SPK_1 / SPK_2 | スピーカーの 2 本の線 |
| TM1637 表示 (任意) | CLK / DIO | GPIO18 / GPIO19 |
| | VCC / GND | **3V3** / GND |
| 圧電ブザー (任意) | + / − | GPIO25 / GND |
| 電解コンデンサ 1000µF | + / − | 5V / GND の間 |

> **TM1637 は 3.3V で使ってください。** モジュール上のプルアップ抵抗が VCC につながっているので、
> 5V で動かすと ESP32 のピンに 5V がかかります。

### 5V と GND の分配

5V と GND をたくさんの部品に配るので、小さなユニバーサル基板や、レバー式の電線コネクタ (WAGO 221 など) で
「5V の束」と「GND の束」を作ると楽です。

## うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| LED リングがちらつく / 色がおかしい | データ線の 330Ω、GND の共通化、配線の短さ。直らなければ LED リングの 5V をダイオード (1N4001 など) 1 本経由にすると安定することがあります (データ信号の 3.3V で受けられるようになるため) |
| 子機のランプが青く点滅し続ける | 親機の電源、`WIFI_CHANNEL` と `GROUP_ID` が親機と同じか |
| 音が出ない | microSD が FAT32 か、`/mp3/0001.mp3` の位置にファイルがあるか。シリアルログに `DFPlayer OK` が出ているか。互換品は `DFPLAYER_SKIP_CHECK=1` で動くことがあります |
| 音を鳴らすと親機がリセットする | 電源容量不足です。`AUDIO_VOLUME` を下げるか、5V 2A 以上の充電器とコンデンサを使ってください |
| ボタンを押しても反応しない | シリアルログに `[press]` が出るか。マイクロスイッチの COM / NO を使っているか |

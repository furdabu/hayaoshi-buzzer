### ボタン内蔵 LED

ボタンの内蔵 LED を状態表示に使います。

- **子機**: 「今押せるとき」だけ光る
- **親機**: 正解・不正解ボタンが「判定待ち (回答者が決まった)」のときに光る

採用しているボタンの LED は **12V 用** なので、子機・親機とも電池の電圧を 2 個目の MT3608 で 12V に上げ、
トランジスタで ON / OFF します ([配線](wiring.md#ボタン内蔵-led-12v))。

### 表示モジュールと DFPlayer の注意

- TM1637 は 0.36 インチ (表示部 約 30 x 14mm) を前提に、親機の手前の壁に 31 x 15mm の窓を開けています。
  0.56 インチなど大きい表示を使う場合は `hardware/enclosure/enclosure.py` の `DISPLAY_WINDOW` を変更してください
- TM1637 は **3.3V** で動かします (詳しくは [配線](wiring.md))
- DFPlayer Mini は互換品 (チップ名 MH2024K / GD3200B など) でも動きますが、起動時の応答確認に失敗することがあります。
  その場合は `config.h` に `DFPLAYER_SKIP_CHECK 1` を設定してください

ほかに、全台で共用できるものとして次を用意してください。

- **充電用**: USB 充電器 (5V 1A 以上) + Type-C ケーブル。子機が多い場合は多ポートの USB 充電器が便利です
- **書き込み用**: 開発ボードの端子 (micro-B / Type-C) に合う USB データケーブル

### 電源ボタンの選び方

ケースは「16mm 金属押しボタン・自己保持型」に合わせています (取付穴 16.2mm, `power_button_d`)。
この種類はメーカー名のない汎用品が多いので、型番よりも次の仕様で選んでください
(検索語の例: 「16mm 金属 押しボタン 自己保持」「16mm latching metal push button」)。

| 確認すること | 理由 |
| --- | --- |
| **自己保持 (ラッチ / オルタネイト)** であること | 押している間だけ ON になる「モーメンタリ」型は電源ボタンに使えない |
| 取付穴 (ネジ部) が **16mm** | ケースの穴に合わせるため |
| 接点定格が **DC 2A 以上** | 子機は 0.2A 程度だが、親機は音とランプが重なると電池側に最大 1.3A 程度流れる |
| 端子が C / NO / NC の 3 本なら **C と NO** を使う | |

型番がはっきりしている例: **SparkFun COM-11975** (Metal Pushbutton - Latching (16mm, White), SPDT, LED 付き)

- LED 付きなら、LED+ を MT3608 の出力、LED− を GND につなぐと「電源 ON の間だけ光る」電源ランプになります。
  **5V 品** は 5V 用 MT3608 の出力へ、**12V 品** は 12V 用 MT3608 の出力へつなげます
- ONPOW の **GQ16** シリーズはデータシート上モーメンタリ型なので、電源ボタンには使えません

### 電池の持ち時間と充電時間 (目安)

| | 電池 | 連続使用 | 充電時間 (1A) |
| --- | --- | --- | --- |
| 子機 | 18650 x1 (2,600mAh) | 約 8〜10 時間 | 約 3 時間 |
| 親機 | 18650 x3 (並列, 7,800mAh) | 約 25 時間 | 約 9 時間 (一晩) |

計算上の値です。子機は 5V で約 110mA + ボタン LED が 12V で約 15mA (ほぼ常に点灯)、親機は 5V で約 150mA
(ボタン LED は判定待ちのときだけ点灯するので省略) として計算しました。
実機での測定はまだしていません。ボタン LED の電流は製品によって違うので、`config.h` の `BUTTON_LED_LEVEL` を下げると電池が長持ちします。

### 電池まわりの注意

- **親機の 3 本を並列につなぐ前に、3 本とも満充電して電圧をそろえてください。**
  電圧の違う電池を並列につなぐと大きな電流が流れて危険です
- 電池は信頼できる販売店のものを選んでください (容量を偽った安価な電池が出回っています)
- TP4056 モジュールは **保護回路 (DW01 + 8205A) 付き** を選んでください。過放電・過充電・短絡から電池を守ります
- Type-C の TP4056 モジュールの中には、**C-to-C ケーブル (PD 充電器) では充電できないもの** があります
  (CC 端子の 5.1kΩ 抵抗が無いため)。その場合は USB-A to C ケーブルで充電してください
- MT3608 は出荷時の出力電圧がばらばらです。**ESP32 をつなぐ前に必ずテスターで 5.0〜5.1V に合わせてください**
  (半固定抵抗を反時計回りに回すと下がるものが多いです)。テスターが無い場合は、出力 5V 固定の昇圧モジュールでも構いません

## 部品選びの注意

### 採用しているボタン

**12V LED 埋め込み式押しボタン 60mm 5 個入り (マイクロスイッチ付き)**
— AliExpress: https://ja.aliexpress.com/item/1005004682547368.html

- 注文するときは色の選択で **「60mm」** のものを選んでください (同じページに 46mm もあり、最初は「Red 46mm」が選ばれています)
- 子機用は好きな色 (例: Red 60mm)、親機用は **Green 60mm と Red 60mm** を 1 個ずつ使います
  (5 個入りなので、子機 64 台 + 親機なら Red 60mm x13 パック + Green 60mm x1 パックなど)
- 価格は 60mm の 5 個入りで約 2,000〜2,100 円 (1 個あたり約 400 円, 2026 年 11 月時点のセール価格)
- 押している間だけ ON (モーメンタリ) のマイクロスイッチ付き。ボタンの中の LED は 12V 用です
- 販売ページに取付穴の寸法は書かれていません。同じ形のボタン (uxcell 60mm, 取付穴 23.5mm) に合わせて、
  ケースの穴は **24.0mm** にしています。届いたらネジ部の太さを測って、違えば
  `hardware/enclosure/enclosure.py` の `button_hole_d` を変えて STL を作り直してください
- 天板の厚さは 3mm です

### LED リングの外径

16 連リングでも外径は 44〜45mm 程度で製品ごとに少し違います。`ring_od` で調整できます。
LED の数を変えた場合は `config.h` の `CHILD_LAMP_LEDS` / `MASTER_LEDS_PER_LAMP` も変更してください。

### 子機 64 台分を揃えるとき

1 台あたりの部品代は ESP32-C3 SuperMini を使うと、電池まわりを含めておよそ 2,500〜4,000 円です (電源ボタンの値段で変わります)。
使うときはケーブル不要で、充電は多ポートの USB 充電器でまとめて行えます。

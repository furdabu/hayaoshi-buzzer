## 部品選びの注意

### アーケードボタンの取付穴

「60mm」はボタン頭の直径で、取付穴の径は製品によって 22〜30mm くらいまでばらつきます。
ケースの初期値は **24.5mm** です。手持ちのボタンのネジ部を測って、
`hardware/enclosure/enclosure.py` の `button_hole_d` を変更してから STL を作り直してください。
天板の厚さは 3mm です (ほとんどのボタンが取り付けられる厚さ)。

### LED リングの外径

16 連リングでも外径は 44〜45mm 程度で製品ごとに少し違います。`ring_od` で調整できます。
LED の数を変えた場合は `config.h` の `CHILD_LAMP_LEDS` / `MASTER_LEDS_PER_LAMP` も変更してください。

### 子機 64 台分を揃えるとき

1 台あたりの部品代は ESP32-C3 SuperMini を使うとおよそ 1,500〜2,500 円です。
USB 充電器を台数分用意する代わりに、USB ハブ型の多ポート充電器や、モバイルバッテリーを使うと配線がすっきりします。
(モバイルバッテリーの中には消費電流が小さいと自動で切れるものがあります。子機は待機中 80〜120mA 程度です)
